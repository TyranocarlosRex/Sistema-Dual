Introduccion

Este documento describe el plan de pruebas unitarias del Sistema de Gestion Dual. Las pruebas unitarias validan clases, servicios, modelos, recursos y reglas de validacion de manera aislada, antes de comprobar flujos completos mediante pruebas de integracion o de sistema.

Objetivo general

Validar que las unidades internas del sistema funcionen correctamente y esten relacionadas con los requerimientos funcionales y no funcionales definidos para la plataforma de Educacion Dual.

Objetivos especificos

Verificar la logica de autenticacion por rol, validar modelos y relaciones principales, comprobar servicios de documentos, validar recursos JSON y asegurar que las reglas de entrada rechacen datos incorrectos.

Conclusion

Las pruebas unitarias validan las unidades internas asociadas a los requerimientos funcionales y no funcionales que pueden comprobarse a nivel de clase, modelo, servicio, recurso y request. Los requerimientos que dependen de rutas, interfaz grafica, navegacion o flujos completos se validan mediante pruebas de integracion o pruebas de sistema.
